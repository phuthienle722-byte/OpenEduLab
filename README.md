## 🛠️ Lệnh Phát triển & Vận hành

```bash
# Cài đặt thư viện
npm install

# Khởi chạy môi trường phát triển (Localhost:3000)
npm run dev

# Kiểm tra kiểu dữ liệu (TypeScript)
npm run lint

# Biên dịch sản phẩm triển khai (Production Build)
npm run build
```
